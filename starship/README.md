# My Starship configuration

## Introduction

This repo contains the configuration file that I use to run the [Starship Cross-Shell Prompt](https://starship.rs)

**Key Features**

- Simple power-line inspired structure
- At-a-glance system information, current working directory, and git info (if applicable)
- Styled using ANSI color names to conform with terminal emulator color schemes and transitions between light and dark modes
- Exit information included when necessary and allows prompt input character to remain static

**Prerequisites**

Before installing, make sure the following are installed on your system:

- [Starship](https://starship.rs/guide/#🚀-installation)
- [A compatible shell](https://starship.rs/guide/#step-2-set-up-your-shell-to-use-starship)
  - Currently only full support for ZSH
  - More to come sometime soon...

## Getting started

**Configuration**

Configuration for starship is handled by TOML. The configuration can be found in the `etc/config.toml` file. This file defines the components and styling of the prompt generated by starship. Explore the [Starship Documentation](https://starship.rs/config/) for a better understanding of the configuration structure and its components.

**Installation**

The configuration needs to be placed in the expected location as specified [here](https://starship.rs/config/#config-file-location). This configuration utilizes the default location. If you place it elsewhere, you dependent shell configuration will also require updating.

Alternately, the `bootstrap` directory contains scripts that are helpful in automating the installation and removal of this configuration.
